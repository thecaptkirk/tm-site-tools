Your business details, notices, and site care tools, kept in one place by Target Marketeer.

== Description ==

Installed on every Target Marketeer client website. Owners get a "Your Business" menu for their
hours, holiday hours, phone, address, and service area, plus a holiday or closing notice that
takes itself down. Target Marketeer switches extra modules on per site with a signed module code.

== Changelog ==

= 0.1.0 (2026-11-23) =
* Stage 1 frame: signed module code, Owner role, Settings > Site Tools, self-update from GitHub.
* Business info (always on): one place for contact details, hours, and holiday hours; [tm_business] shortcode; LocalBusiness markup.
* Notices: top-of-site banner with first and last day, ready-made messages, take-down button, cache purge at start and end.
* SEO basics: Google and Bing verification tags, generated /llms.txt, users list out of the sitemap, search results noindex.
* Support link: "Need help?" toolbar item and dashboard box.
